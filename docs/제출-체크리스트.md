## 4. 보안 점검 (제출 전 필수)

| 확인 | 방법 | 상태 |
|---|---|---|
| 코드에 API 키가 없는가 | 저장소에서 `sk-`, `AIza` 로 검색 | ✅ |
| README에 키가 없는가 | 6절은 **이름만** 적혀 있음 | ✅ |
| 스크린샷에 키가 없는가 | `17_vercel_환경변수.png` 확인 | 🔲 |
| `.env` 파일이 커밋되지 않았는가 | `.gitignore` 첫 줄에 등록됨 | ✅ |
| 배포 주소가 실제로 열리는가 | 다른 기기·다른 브라우저에서 접속 | 🔲 |

### 저장소에서 키 검색하는 법

GitHub 저장소 화면에서 **`/`** 키를 누르고 아래를 검색합니다.

```
AIza
```

**검색 결과가 0건이어야 합니다.** (제미나이 키는 `AIza` 로 시작합니다)

## 5. 제출 직전 최종 확인 5가지

- [ ] 배포 주소를 **다른 기기(휴대폰 등)** 로 열어 정상 동작하는지 확인
- [ ] 배포 주소에서 **AI 기능이 실제로 결과를 내는지** 한 번 더 실행
- [ ] GitHub 저장소가 **Public** 인지 확인 (로그아웃 상태로 접속)
- [ ] 스크린샷 **굵게 표시된 5장**이 모두 있는지 확인
- [ ] 스크린샷에 **API 키가 노출되지 않았는지** 확인
